Key invariants (all three layouts):
  - The agents/ parent directory holds your agent package (e.g. agents/my_agent/).
  - my_agent/__init__.py imports `agent` so adk CLI can find `root_agent`.
  - my_agent/agent.py exposes `root_agent = ...` at module top.
