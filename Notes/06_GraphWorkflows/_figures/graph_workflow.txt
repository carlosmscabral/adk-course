──────────────────────────────────────────────────────────────────────────
node-kind cheat sheet
──────────────────────────────────────────────────────────────────────────
  LlmAgent              — passes user/upstream input through as a turn
  FunctionNode(fn)      — wraps an async generator; yields state/route/content
  ParallelWorker(agent) — runs `agent` once per upstream-list-element, in parallel
  WorkflowAgent         — nests! a whole workflow becomes a node in a bigger one

──────────────────────────────────────────────────────────────────────────
edge tuple cheat sheet
──────────────────────────────────────────────────────────────────────────
  (A, B)               always: A → B
  (A, B, C)            chain: A → B → C
  (A, B, "LABEL")      conditional: A → B only if A yields Event(route="LABEL")
  multiple chains      overlay into one graph
