# 📦 ADK Python 2.0 GA — release-note absorption (the snapshot this course was authored against)

This is the **baseline release** the entire course is built on. Future `YYYY-MM_release.md` files in this folder will be *deltas* against this one. If you are reading this as a student, you do not need to act on it — it is here so the tutor and future authors can see what the surface looked like at authoring time.

---

## What's new in 2.0 (first-class in this course)

### Composition & orchestration

- **Graph-based `Workflow`** (from `google.adk.workflow`) — the 2.0 primary workflow primitive. Nodes + edges + dynamic routing + human-in-the-loop pauses. Taught in [Notes/06_GraphWorkflows/](../06_GraphWorkflows/). Replaces the 1.x `WorkflowAgent` name.
- **Collaborative agents** — a new composition pattern alongside `sub_agents` / `AgentTool` / `transfer_to_agent`. Covered in [Notes/05_MultiAgent/](../05_MultiAgent/).
- **Visual Builder** — a UI for assembling agent graphs without writing the wiring code. Detour: [Notes/Detours/VisualBuilder.md](../Detours/VisualBuilder.md). Referenced from Modules 02 and 06.

### Runtime

- **Resume / Cancel** on `Runner` — long-running agents can be paused and resumed across processes. Covered in [Notes/02_FirstAgent/](../02_FirstAgent/) (briefly) and [Notes/06_GraphWorkflows/07_HumanInTheLoop](../06_GraphWorkflows/07_HumanInTheLoop.md) (in depth).
- **Session rewind / migrate** — `SessionService` API for rewinding a session to a prior turn and migrating sessions across services. Covered in [Notes/04_SessionsState/](../04_SessionsState/).
- **Context caching / compression** — automatic context window management with `before_model_callback`-style hooks. Covered in [Notes/07_Callbacks/](../07_Callbacks/) and [Notes/15_Observability/](../15_Observability/) (cost implications).
- **Ambient Agents** — agents that run continuously in the background, reacting to events rather than turn-by-turn. Mentioned in [Notes/02_FirstAgent/](../02_FirstAgent/), deep-dived in [Notes/06_GraphWorkflows/](../06_GraphWorkflows/) (because graph + ambient compose naturally).

### Configuration & packaging

- **Agent Config** — a declarative YAML-ish format for defining agents without Python boilerplate. Covered in [Notes/02_FirstAgent/](../02_FirstAgent/) as an alternative to the hand-wired path.
- **Skills (`Skill`, `Script`, `Frontmatter`, `SkillToolset`, `SkillRegistry`)** — file-based reusable capability packaging. Module [Notes/09_Skills/](../09_Skills/) is dedicated to this.

---

## Still supported (legacy but not deprecated)

- **`SequentialAgent`, `ParallelAgent`, `LoopAgent`** — the pre-2.0 template workflow primitives. Many existing samples still use them. The course teaches them in [Notes/06_GraphWorkflows/01_LegacyTemplates.md](../06_GraphWorkflows/01_LegacyTemplates.md) so the student can read older samples, then pivots to the graph workflow as the modern story.

> 🤖 **Tutor note:** when a student reads a sample that uses Sequential/Parallel/Loop, do not say it is deprecated. It is not. Say it is the legacy template and that the modern equivalent would use the graph workflow. Both are fine; the choice is taste + when the codebase started.

## Full surface (what the course covers)

### Agents
`LlmAgent` (alias `Agent`), `BaseAgent`; `SequentialAgent`, `ParallelAgent`, `LoopAgent`; **graph `Workflow` (NEW 2.0; from `google.adk.workflow`)**; **collaborative agents (NEW 2.0)**; `RemoteA2aAgent`; `LangGraphAgent`.

### Runtime
`Runner`, `InMemoryRunner`, `runner.run_async()` → async iterator of `Event`. **Resume / Cancel (NEW 2.0)**.

### Session services
`InMemorySessionService`, `DatabaseSessionService`, `VertexAiSessionService`, `SqliteSessionService`. **Session rewind / migrate (NEW 2.0)**.

### State prefixes
no-prefix (session-scoped) · `user:` · `app:` · `temp:`.

### Events
`author`, `content`, `actions` (`state_delta`, `artifact_delta`, `transfer_to_agent`, `escalate`, `skip_summarization`).

### Tools
`BaseTool`, `FunctionTool`, `LongRunningFunctionTool`, `AgentTool`, `ToolContext`, `McpToolset`, **`SkillToolset` (NEW 2.0)**. Built-ins: `google_search`, `load_memory`, `exit_loop`, `transfer_to_agent`.

### Models
Gemini · Claude (via Vertex) · Gemma · `LiteLlm` · `OpenAILlm` · `ApigeeLlm` · `LLMRegistry`.

### Memory
`InMemoryMemoryService`, `VertexAiMemoryBankService`, `VertexAiRagMemoryService`.

### Callbacks
`before/after_model_callback` · `before/after_tool_callback` · `before/after_agent_callback` · `on_model_error_callback` · `on_tool_error_callback`.

### Plugins
`LoggingPlugin`, `ReflectAndRetryToolPlugin`, `ContextFilterPlugin`, `GlobalInstructionPlugin`, `BigQueryAgentAnalyticsPlugin`.

### Skills (NEW 2.0)
`Skill`, `Script`, `Frontmatter`, `SkillToolset`, `SkillRegistry`.

### A2A
`AgentCard`, `to_a2a(root_agent)`, `RemoteA2aAgent`.

### Code execution
`UnsafeLocalCodeExecutor` (dev only) · `BuiltInCodeExecutor` · `VertexAiCodeExecutor` · `ContainerCodeExecutor` · `GkeCodeExecutor` · `AgentEngineSandboxCodeExecutor`.

### Evaluation
`AgentEvaluator`, `EvalCase`, `EvalSet`, `LlmAsJudge`, `RubricBasedEvaluator`, `TrajectoryEvaluator`, `HallucinationsV1`, `FinalResponseMatchV1/V2`.

### CLI
`adk run` · `adk eval` · `adk web` · `adk create` · `adk deploy`.

### Live
Gemini Live API (bidi voice/video, gRPC under the hood).
